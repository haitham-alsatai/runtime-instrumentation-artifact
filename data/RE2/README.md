# RCAEval RE2 Data

Raw RCAEval data is not redistributed.

Download RCAEval from:

https://github.com/phamquiluan/RCAEval

Place the extracted RE2 systems here:

```text
data/RE2/
  RE2-OB/
  RE2-TT/
```

The Stage A scripts discover numeric experiment instances containing
`traces.csv`. The completed study used 90 usable cases per system.
