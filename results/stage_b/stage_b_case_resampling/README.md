# Stage B Case-Resampling and Fault-Macro Summary

This folder derives the paper's Stage B uncertainty and subgroup summaries from the stored zero-corruption weak-anchor case outputs.

- Randomized policies are averaged per case across five repetitions.
- Bootstrap intervals use 10,000 nonparametric case-resampling replicates.
- Fault-macro values assign equal weight to each observed fault type.
- These are derived analyses over stored outputs, not experiment reruns.
